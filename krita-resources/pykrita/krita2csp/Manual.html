Krita2CSP

A Clip Studio Paint style interface for Krita 6.

  • Tool: CSP-like tool palette. Pen, Pencil, Brush, Airbrush, Decoration, Eraser and Blend are groups of Krita brush presets; the other entries switch to Krita tools.
  • Sub Tool: the brushes or tools of the selected entry. Use + to add the current brush to the group, − to remove one, ↺ to restore the defaults.
  • Tool Property: brush size, opacity, density and pen pressure. Krita's own Tool Options sit in the tab next to it (stabilizer, fill and selection settings).
  • Brush Size: one click size presets.

Shortcuts (set by install.sh): P = Pen/Pencil, B = Brush/Airbrush/Decoration, E = Eraser, J = Blend. Press the key again to switch to the next tool in the group.

To restore the layout: Tools > Scripts > Apply CSP layout.
